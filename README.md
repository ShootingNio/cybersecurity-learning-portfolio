## About This Portfolio

Welcome to my Cybersecurity Learning Portfolio.

This repository documents my ongoing journey into cybersecurity, combining academic knowledge with hands-on technical practice. It serves as a structured record of the concepts I study, the tools I explore, the laboratories I complete, and the technical investigations I conduct.

My goal is to develop a strong foundation in cybersecurity while progressively exploring advanced areas such as network security, cryptography, threat hunting, digital forensics, penetration testing, cloud security, and AI security.

## Learning Methodology

My approach to learning cybersecurity follows five principles:

**Understand** — Study the underlying concepts, technologies, and security principles.

**Practice** — Apply theoretical knowledge through hands-on exercises and controlled laboratory environments.

**Investigate** — Analyze system behavior, network traffic, security configurations, and potential vulnerabilities.

**Document** — Record procedures, commands, observations, results, and technical conclusions.

**Improve** — Review previous work, identify knowledge gaps, and progressively increase technical complexity.

*The objective is not simply to complete exercises, but to develop the ability to understand, investigate, and explain technical security problems.*
