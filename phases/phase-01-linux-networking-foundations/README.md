# Phase 01 — Linux, Networking & Foundations

## Phase Overview

This phase establishes the technical foundations required for further cybersecurity studies and practical investigations.

The focus is on understanding Linux systems, networking fundamentals, command-line environments, and basic network analysis. Through structured practices and hands-on exercises, I will develop the ability to interact with operating systems, inspect network configurations, analyze network traffic, and understand essential communication protocols.

The objective is to build a solid technical foundation before progressing into more advanced cybersecurity domains.

## Learning Objectives

By completing this phase, I aim to:

- Develop practical Linux command-line and system administration skills.
- Understand filesystem navigation, permissions, processes, and system services.
- Understand networking fundamentals, including IP addressing, interfaces, routing, and network communication.
- Analyze basic network traffic using Wireshark.
- Understand essential protocols such as ICMP, ARP, DNS, and SSH.
- Perform basic network troubleshooting and connectivity analysis.
- Work with remote connections and secure file transfers.
- Develop technical documentation and reproducible laboratory practices.

## Core Topics

### 1. Linux Fundamentals

- Linux architecture and distributions.
- Terminal navigation and command-line operations.
- Filesystem hierarchy and file management.
- Users, groups, ownership, and permissions.
- Processes and system services.
- Package management and system administration.
- Basic Bash scripting and command-line utilities.

### 2. Networking Fundamentals

- OSI and TCP/IP models.
- IPv4 addressing and subnetting fundamentals.
- Network interfaces and configuration.
- MAC addresses and ARP.
- ICMP and network connectivity.
- DNS resolution and domain name infrastructure.
- Basic routing and network troubleshooting.
- TCP and UDP fundamentals.

### 3. Network Analysis & Security Foundations

- Introduction to packet analysis.
- Wireshark interface and capture fundamentals.
- Understanding packet structure and protocol layers.
- Analyzing ICMP, ARP, DNS, and SSH traffic.
- Identifying basic network communication patterns.
- Introduction to network reconnaissance and security analysis.

### 4. Remote Access & Secure File Transfer

- SSH fundamentals and client configuration.
- Public-key and private-key authentication.
- SSH key generation and management.
- SSH agent fundamentals.
- Secure file transfer using SFTP.
- Introduction to secure remote administration.

## Learning Outcomes

By the end of this phase, the objective is to demonstrate the ability to:

- Navigate and administer Linux environments using the command line.
- Understand fundamental operating system components and services.
- Interpret basic network configurations and communication.
- Analyze network traffic and identify common protocols.
- Perform basic DNS queries and network troubleshooting.
- Establish secure remote connections and transfer files using SSH and SFTP.
- Document technical procedures and explain observed results.

These foundations will support the transition into Phase 02 — Advanced Networking, Cryptography & OSINT.
